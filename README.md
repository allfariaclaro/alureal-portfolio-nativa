# NATIVA — projeto conceitual Alureal

E-commerce fictício de objetos e cuidados para casa, criado para demonstrar uma experiência de compra editorial, responsiva e direta.

## Recursos
- catálogo filtrável;
- carrinho demonstrativo;
- contador e total em tempo real;
- checkout conceitual;
- direção de arte de marca;
- GitHub Pages.

> Projeto conceitual. Produtos, preços e marca são fictícios.
